# LEXPIN - Análisis de Datos con Python (2da. Edición)

Este repositorio contiene los materiales y ejemplos correspondientes a la segunda edición del curso "Análisis de Datos con Python" de LEXPIN. Aquí encontrarás notebooks, scripts y recursos adicionales para aprender y aplicar técnicas de análisis de datos utilizando Python.

## Contenido

### Fundamentos de Python

Contiene ejemplos y ejercicios relacionados con los conceptos básicos de Python, como variables, operadores y estructuras de control.

### Proyectos de demostración

- `proyecto-starbucks`: Contiene un proyecto de demostración que analiza datos pertenecientes a las bebidas de Starbucks.
- `proyecto-toyota`: Contiene un proyecto de demostración que analiza datos relacionados con los vehículos de Toyota.

### Plantilla para proyectos

Contiene una estructura base y archivos de ejemplo que pueden ser utilizados como punto de partida para nuevos proyectos de análisis de datos con Python.

- `plantilla-proyecto`: Carpeta que incluye la estructura y archivos iniciales para crear un nuevo proyecto de análisis de datos.

## ¿Cómo utilizar este contenido?

Para aprovechar al máximo los materiales de este repositorio, sigue estos pasos:

1. Explora los fundamentos de Python para familiarizarte con los conceptos básicos.
2. Revisa los proyectos de demostración para ver ejemplos prácticos de análisis de datos.
3. Utiliza la plantilla de proyecto como punto de partida para tus propios análisis.
4. Consulta los notebooks y scripts incluidos para aprender técnicas específicas y buenas prácticas en el análisis de datos con Python.
5. Aplica lo aprendido en tus propios proyectos, utilizando la plantilla y los ejemplos como referencia.
